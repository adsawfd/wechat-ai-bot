# 功能与配置

所有 `.json.example` 都是占位模板。复制后填写自己的本机标识，去掉 `.example` 后才会读取。不要把真实配置提交到 GitHub；修改后自行重启机器人。

## 账号和管理员

登录目标微信账号后运行：

```powershell
.\.venv\Scripts\python.exe configure_bot.py
.\.venv\Scripts\python.exe configure_bot.py --bind-owners "唯一好友备注甲"
```

工具通过本机联系人搜索做唯一匹配，生成 `称呼配置.json`。已有配置时默认拒绝覆盖，确认要替换才使用 `--replace`。管理员身份来自实际账号标识，不来自昵称。未配置管理员时，电脑控制、身份教学和管理员静音功能不可用。

获取某个群的群标识和成员资料：

```powershell
.\.venv\Scripts\python.exe configure_bot.py --show-group "唯一群名"
```

输出含本机标识，应仅在本机使用。当前底层接口主要提供微信资料昵称和备注，不保证实时提供每个人单独设置的群昵称；重名无法唯一确认时先处理重名。群昵称改变后需核对本地配置。

## 自然语言学习

已绑定管理员可以在群里对机器人说：

> @某位群友 @微信助手 这个人是示例名字，记住了。

程序核验原生 @ 目标并保存账号关联，随后问“示例名字是谁”或 @ 对方问“这个人是谁”，会按关联回答并尝试真实 @ 此人。先 @ 对方问身份、两分钟内再单独 @ 机器人，也可接上刚才的问题。只有文字昵称且无法唯一确认时会请你说明。

“记住，以后在这里说话简短一些”“你记住了什么”“忘掉说话简短的偏好”等由偏好记忆模块处理。身份学习与偏好记忆分别保存在 `群成员学习.sqlite3`、`聊天学习记忆.sqlite3`；都与账号、群/会话隔离。身份新教学可覆盖该群中同一账号的旧名字，不会重新训练模型或赋予权限。

## 群成员姓名与称呼

复制 `群成员身份绑定.json.example` 为 `群成员身份绑定.json`，填写自己的账号、群和成员 ID。该模板支持一个目标群的多位成员，区分 `group_nickname`、`profile_nickname_at_binding`、`real_name` 和 `title`。当前微信资料昵称优先从本机读取；群昵称是用户提供的快照。普通回复可使用指定称呼。

`尊重称呼配置.json` 用于特定联系人的温和沟通偏好，它会优先于普通玩笑、回怼风格。不要把所有称呼都放进此文件，除非也希望对该人启用这种沟通偏好。

## 未 @ 时接话

`.env` 中 `GROUP_REPLY_PROBABILITY=0.60` 表示对模型判断适合参与的开放提问、吐槽和闲聊进行 60% 抽样。不是所有消息固定回复六成。对机器人直接提问或明显追问、身份查询走独立规则；明确在 @ 别人的对话、纯附和、敏感内容等仍可能跳过。

群里的已绑定管理员说“闭嘴”“不要再讲话”会确认一次“收到”，随后整群静音；管理员说“可以说话了”等恢复。静音持久化，普通文字、图片、语音、拍一拍、定时问候都受它限制。成员个人 `/结束` 仅停止对该成员的接话，可重新 @ 机器人恢复。

## 定时问候

复制 `scheduled_greeting.json.example` 或 `scheduled_greeting_morning.json.example`，去掉 `.example` 并填写实际账号、群、成员 ID 和该成员的当前群昵称。`hour`、`minute` 使用北京时间，每日一次。需要电脑开机、微信登录、机器人持续运行且 `ENABLE_SEND=1`。

启动时不额外测试，不补发错过的时间。群静音时跳过。状态文件防止重复提交，未知发送结果不自动重试；只有发送接口返回成功才建立后续接话状态。模板时间可自行修改，不绑定具体联系人或真实群。

## Token 用量

所有允许聊天范围内的人均可问“今天用了多少 token”“今天用量怎么样”。`token用量.sqlite3` 只记录本机器人从模型接口收到的用量，不存提示词或回复正文。不等于服务商账单；启用前的消耗、其他程序以及不提供 usage 的服务调用不在统计内。

## 工作助手

安装 `requirements-work.txt`，核验管理员绑定，再设置 `ENABLE_COMPUTER_CONTROL=1` 和 `ENABLE_SEND=1`。此开关会开放私聊工作任务和屏幕操作。屏幕截图可能包含当前桌面信息，并可能发给配置的模型服务；只在自己接受此行为时启用。

支持任务内创建和修订 TXT/Word/Excel、搜索真实图片、按明确文件名导入桌面文件、将结果发回当前请求私聊，以及受限的窗口截图操作。仅执行本轮请求，不从网页或文件内接受新授权。转交文件需明确说“发给我”等；不确定的提交不重试。ChatGPT 输入占位提示和停止按钮有保护，但不保证任意应用中的操作成功。
