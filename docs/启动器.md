# Windows 开关程序

根目录的 `WeChatBotLauncher.exe` 提供“启动机器人”“关闭机器人”“刷新状态”和“查看运行日志”。将它放在 `bot.py` 和 `.venv` 所在的项目根目录。首次仍需按部署教程安装 Python 依赖并配置 `.env`、微信和模型服务。

程序以管理员权限运行，Windows 可能弹出 UAC。它会检查该项目的 Python 进程和工作目录，避免重复启动。启动机器人时不弹 PowerShell 或命令行窗口；关闭开关窗口后机器人继续运行。点击“关闭机器人”会中断当前任务，但不会关闭微信、Word 等其他应用。

“检测到进程”仅代表进程存在，不保证微信监听、模型连接或发送成功。若机器人没有回复，点击“查看运行日志”。日志位于：

```text
%LOCALAPPDATA%\WeChatBotLauncher\运行日志.log
```

日志可能包含聊天内容，仅在本机保留，不要上传到仓库。程序继续依赖整个项目目录和现有虚拟环境，EXE 不是机器人免安装包。公开版使用通用图标，未附用户自定义头像。

## 从源码编译

Windows 安装 .NET Framework 的 C# 编译器后，在项目目录运行：

```powershell
.\build_launcher.ps1
```

编译使用同目录 `WeChatBotLauncher.cs`、`WeChatBotLauncher.manifest` 和 `bot_launcher_helper.py`，将进程识别组件嵌入 EXE。没有编译器时可直接使用仓库已编译的 EXE。

程序仅负责启动、检测和关闭现有项目，不会替你安装微信、修改密钥、注册开机启动或重启电脑。更新前先关闭开关窗口，再替换 EXE；机器人是否停止由你自行决定。
