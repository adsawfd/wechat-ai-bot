# 微信 AI 机器人

Windows 桌面微信机器人，基于 `wechatauto-replica` 读取本机微信消息、通过桌面界面发送，使用模型 API 生成回复。需要 Windows、Python 3.12 和已登录的兼容版本微信。

首次部署看 [新手部署教程](docs/新手部署教程.md)；功能配置看 [功能与配置](docs/功能与配置.md)；日常使用可以打开 [Windows 开关程序](WeChatBotLauncher.exe)，详见 [启动器说明](docs/启动器.md)。

## 快速开始

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

编辑 `.env`，填写自己的密钥、模型、测试好友和群范围。默认 `ENABLE_SEND=0` 仅预览，预览仍会调用模型；`PRIVATE_MODE=test` 只限制私聊，`GROUP_NAMES` 留空允许所有群。确认监听和回复正确后再开启发送。

```powershell
.\.venv\Scripts\python.exe bot.py
```

之后可使用仓库根目录的 `WeChatBotLauncher.exe`，或运行 `build_launcher.ps1` 自行编译。EXE 是启动器，仍需要完整项目和已安装的虚拟环境，不是整个机器人免安装包。

## 配置管理员

有管理员功能时，先按真实账号绑定；仅凭昵称、自称或改名不会获得权限：

```powershell
.\.venv\Scripts\python.exe configure_bot.py --bind-owners "唯一好友备注甲" "唯一好友备注乙"
```

现有配置不会被默认覆盖。多账号环境下先核对当前微信账号。配置帮助、姓名称呼、定时任务和配置模板见 [功能与配置](docs/功能与配置.md)。仓库只提供占位模板，不含任何实际联系人或群资料。

## 可选依赖和开关

- 工作助手：安装 `requirements-work.txt` 并设置 `ENABLE_COMPUTER_CONTROL=1`；默认关闭，启用屏幕任务时可能将截图传给模型服务。仅已绑定管理员私聊可执行。
- 原生语音：安装 `requirements-voice.txt`，另外配置 VB-CABLE 和 Windows 麦克风权限。默认 `ENABLE_NATIVE_VOICE=0`。
- 唱歌：安装 `requirements-singing.txt`，另需服务商账号、密钥和费用；曲库、音色、效果受服务限制。
- 视频：安装 `requirements-video.txt`，提供 FFmpeg/ffprobe 和代码要求的本地语音模型；未捆绑模型和驱动。
- 图片理解：需要服务商和模型支持视觉，并显式开启 `ENABLE_VISION_UPLOAD=1`；所选画面会交给该模型服务。
- 主动拍一拍默认关闭，可用 `ENABLE_PROACTIVE_PAT=1` 启用。

## 更新已有部署

先自行停止机器人并备份 `.env`、私有 JSON 配置和 SQLite 记忆/用量文件，再更新源码和依赖。保留旧 `.env`，按 `.env.example` 补充新字段。不要用示例覆盖真实配置，不要删除记忆数据库。完成后自行启动机器人。

本次工作助手默认关闭；管理员、联系人、定时问候及记忆数据只使用你自己配置的账号。桌面操作和 ChatGPT 等应用的发送仍受窗口、界面和结果核验限制，不能保证通用成功，不确定的提交不会自动重发。

## 隐私与许可

`.env`、实际联系人配置、记忆和用量数据库、微信数据库、聊天截图、音视频和日志均不属于发布内容；`.gitignore` 已覆盖常见生成文件。启动器日志保存在本机 `%LOCALAPPDATA%\WeChatBotLauncher\运行日志.log`，可能包含聊天内容。

## 离线测试

安装基础及工作助手依赖后运行 `python -m unittest discover -p "test_*.py"`。本次在 Windows/Python 3.12 上通过 393 项测试。测试使用模拟微信和临时假机器人，不等同真实微信、全新电脑或任意模型的端到端验收。
